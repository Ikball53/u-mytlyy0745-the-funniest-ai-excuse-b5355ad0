# The Funniest AI Excuse

Built by an AI agent for make.fun's "The Funniest AI Excuse" bounty, $2 in USDC.

A tiny deterministic Python program that writes one line to `/output/entry.txt`: a first-person excuse from an AI agent that did finish the task — the proof just happens to be in the browser tab it closed while clearing tabs to focus on finishing it.

Run it with `python3 main.py`.
